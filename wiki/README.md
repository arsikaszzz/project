# Хроники Архитекторов · Esoteric Wiki

Премиальный одностраничный сайт-энциклопедия по эзотерическим знаниям:
космология, иллюзия плотного мира, скрытая история и путь освобождения.

## Стек

- **React 19 + TypeScript** на базе **Vite**
- **React Router v6** для маршрутизации между категориями и статьями
- **Vanilla CSS3** (CSS Variables, Grid/Flexbox, `backdrop-filter`)
- **Lucide React** для минималистичных SVG-иконок
- Google Fonts: **Inter** (UI) + **Cinzel** (заголовки)

```
wiki/
├── src/
│   ├── components/
│   │   ├── Layout.tsx        ← оболочка с боковой панелью и мобильным меню

│   ├── pages/

│   │   ├── CategoryView.tsx  ← статьи внутри категории
│   │   └── ArticleView.tsx   ← статья с дроп-капсом, тегами, breadcrumbs
│   ├── styles/global.css     ← темная премиум-тема, анимации, glassmorphism
│   ├── data.ts               ← база знаний (категории + статьи)
│   ├── types.ts              ← TS-типы доменной модели
│   ├── App.tsx               ← роуты
│   └── main.tsx              ← bootstrap + BrowserRouter
└── index.html
```

## Как пополнять базу знаний

Все статьи и категории описаны в `src/data.ts` — простые массивы объектов
типизированных через `src/types.ts`. Чтобы добавить статью:

```ts
{
  id: "novyy-kontsept",
  categoryId: "matrix",
  title: "Новый концепт",
  subtitle: "Подзаголовок",
  excerpt: "Короткое описание для карточки.",
  body: [
    "Первый абзац...",
    "Второй абзац...",
  ],
  tags: ["тег1", "тег2"],
}
```

Категории добавляются по аналогии в массив `categories` — иконка (emoji),
slug для URL, акцентный цвет.

## Дизайн

- **Глубокая темная тема** с CSS-переменными для лёгкой темизации
- **Анимированный фон**: дрейфующие градиентные сферы + параллакс звёздной пыли
- **Glassmorphism** для боковой панели и карточек (`backdrop-filter: blur`)
- **Hover-эффект**: подъём карточки + радиальное свечение, следящее за курсором
- **Свечение заголовков** через градиентный `background-clip: text`
- **Дроп-кап** в первом абзаце статьи
- **Полная адаптивность**: при ширине ≤ 960px появляется бургер-меню
